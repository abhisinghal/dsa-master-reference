Amazon's SDE II / SDE III / Principal loops emphasize **Trees**, **Graphs**, **Sliding Window**, and **DP** — with a **strong Leadership Principles component** that requires you to weave "customer obsession" or "ownership" narratives into your solution walkthrough.

## What Amazon looks for by level

| Level | Focus |
|---|---|
| **SDE I** | Arrays, strings, hashing, trees, easy DP |
| **SDE II** | Medium graph, sliding window, backtracking, medium DP |
| **SDE III / Principal** | Hard graphs, hard DP, system design + algorithm blend |

## What Amazon interviewers care about

- **Leadership Principle stories.** Every solution should map to a principle: "This code shows *Customer Obsession* because…"
- **Practical over academic.** Amazon prefers "readable + shippable" over "clever + optimal."
- **Handle production concerns.** What if input is empty? What if two things fail concurrently?
- **Bar Raiser round.** One interviewer will be from a different org — expect a hard behavioral + algorithmic mix.
